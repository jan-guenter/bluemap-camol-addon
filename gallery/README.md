# Minimal Camol gallery

Install the datapack, run `/function camol_gallery:build`, connect with the
matching All the Mons client, run `/function camol_gallery:tools`, and apply
the issued items to the targets in the order printed in chat. Run
`/function camol_gallery:pose` for the overview.

The cells cover stock, equal-looking normal/solid opaque camouflage, a partial
stair overlay, transparent glass over a contrasting host, adjacent opaque
camouflage, and a directional log. Commands cannot directly write NeoForge
chunk attachments, so the six right-clicks are intentionally the smallest
honest fixture setup.
